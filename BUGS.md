## How to read this report

| Field | Meaning |
|---|---|
| **Category** | Type of failure (see list below) |
| **Severity** | 🔴 High = call-breaking · 🟡 Medium = degraded UX · 🟢 Low = minor |
| **Turn** | Conversation turn number where the bug occurred |
| **Description** | Human-readable explanation |
| **Agent said** | Exact agent utterance demonstrating the bug |

### Bug categories

| Category | Description |
|---|---|
| `misheard_name` | Agent mis-transcribed or mis-repeated a name/word |
| `wrong_date_time` | Date or time offered/confirmed was incorrect |
| `dropped_context` | Agent forgot earlier information in the same call |
| `incorrect_confirmation` | Agent confirmed wrong details |
| `unexpected_silence` | Agent went silent for >3 s without explanation |
| `scripted_loop` | Agent repeated the same phrase or question unnecessarily |
| `invalid_information` | Agent provided factually wrong information |
| `poor_error_handling` | Agent crashed, errored, or gave a generic error response |
| `missing_field_prompt` | Agent failed to ask for required information |
| `other` | Any other observable issue |
